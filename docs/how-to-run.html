Car Rental App — Project Setup & Run Guide

Prerequisites

Required Software

  • Java 26+ (JDK) — Download from Adoptium
  • Node.js 18+ — Download from nodejs.org
  • Maven 3.9+ — Download from apache.org
  • PostgreSQL 14+ — running on localhost:5432

Database Setup

-- Run in PostgreSQL (psql or pgAdmin)
CREATE DATABASE car_rental;

Method 1: run.bat (Windows - Easiest)

Double-Click run.bat

Easiest
1 Open the project folder in File Explorer
2 Double-click run.bat
3 Two terminal windows will open — one for backend, one for frontend
4 Wait ~15 seconds for both to start
5 Browser opens automatically to http://localhost:5173
Note: Do NOT double-click index.html directly. Always use run.bat or npm run dev so the video background loads.

Method 2: VS Code

Visual Studio Code

Easy
1 Open the project folder in VS Code: File > Open Folder > D:\cr

Start Backend

# Open Terminal 1: Ctrl + ` (backtick)
cd backend
C:\apache-maven-3.9.9\bin\mvn.cmd clean spring-boot:run

Start Frontend

# Open Terminal 2: Click "+" in terminal panel
cd frontend
npm run dev

Access the App

Open browser → http://localhost:5173
Common Error: "Maven project configuration required" — This is just a VS Code Java extension warning. Ignore it. The backend still runs fine from the terminal.

Method 3: IntelliJ IDEA

IntelliJ IDEA

Medium

Backend

1 File > Open — select D:\cr\backend\pom.xml
2 Click "Open as Project" when prompted
3 Wait for Maven sync (bottom-right status bar)
4 Navigate to src/main/java/com/carrental/CarRentalApplication.java
5 Right-click → Run 'CarRentalApplication'

Frontend (in IntelliJ Terminal)

# Open IntelliJ Terminal: View > Tool Windows > Terminal
cd frontend
npm run dev
Troubleshooting:
  • If "Run" button is greyed out: File > Invalidate Caches > Invalidate and Restart
  • If JDK not found: File > Project Structure > SDK > Add JDK → select your Java 26 install
  • Make sure IntelliJ uses the same Maven path: Settings > Build > Build Tools > Maven

Method 4: Eclipse

Eclipse IDE

Medium

Backend

1 File > Import > Maven > Existing Maven Projects
2 Browse to D:\cr\backend → click Finish
3 Wait for Maven dependencies to download
4 Find CarRentalApplication.java in src/main/java/com/carrental/
5 Right-click → Run As > Java Application

Frontend (in Eclipse Terminal)

# Open Eclipse Terminal: Window > Show View > Terminal
cd frontend
npm run dev
Note: Eclipse requires the M2Eclipse (m2e) plugin for Maven support. Install it from Help > Eclipse Marketplace if not already present.

Method 5: Command Prompt / Terminal (Any OS)

Standalone Terminal

Easy 
:: Terminal 1 — Backend
cd /d D:\cr\backend
mvn clean spring-boot:run

:: Terminal 2 — Frontend
cd /d D:\cr\frontend
npm run dev
Linux/Mac: Replace cd /d with cd. If mvn is not in PATH, use the full path or ./mvnw spring-boot:run.

Common Issues & Fixes

ProblemFix
"Cannot connect to server. Make sure the backend is running on port 8081." Backend is not running. Start it with mvn spring-boot:run and wait 10-15 seconds.
"Unsupported class file major version 69" Java version mismatch. Your system has Java 26. Make sure pom.xml uses Spring Boot 4.1.0+.
Background video not loading You opened index.html directly. Use npm run dev and open http://localhost:5173 instead.
PostgreSQL connection refused Make sure PostgreSQL is running on port 5432 and the car_rental database exists.
mvnw.cmd not found The project uses a global Maven install. Use mvn directly or set the full path.
npm errors / node_modules missing Run npm install in the frontend directory first.
